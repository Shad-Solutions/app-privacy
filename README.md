# app-privacy

Privacy policies for SHAD's apps, served via GitHub Pages.

**Generated, not hand-written.** Each page is produced from its app's `manifest.json` by
`scripts/build-privacy.ts` in the app-factory repo. A policy therefore cannot claim
something the app contradicts, and an app that changes what it collects gets its policy
updated in the same commit.

Do not edit these files directly. Change the app manifest and regenerate.
